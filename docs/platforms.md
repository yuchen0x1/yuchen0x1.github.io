# 平台评估与兼容性

评估日期为 2026-11-18。产品用途是向访问者展示开发者、公开项目和 GitHub 数据。核心功能需要浏览器渲染、HTTPS、公开快照和可选的本地缓存。设备端没有文件管理、通知、付费权限或专属硬件依赖。

A 表示直接适合，B 表示有价值且需要适配，C 表示当前投入产出比低，D 表示存在业务或技术限制。测试记录中的 PASS 表示实测通过，PARTIAL 表示部分验证，BLOCKED 表示外部环境阻塞。

Windows、Linux、macOS、Android 与 iOS 的独立原生客户端列为 C。当前业务不涉及原生窗口管理、托盘、Keychain、后台任务或系统文件管理。专属客户端会增加证书、商店与安装包维护成本。相关分发形式包括 EXE、MSI、DEB、RPM、Flatpak、DMG、PKG、APK 和 AAB，本轮交付采用浏览器和 PWA 体验。

PWA 的业务核心沿用 React 数据模型，系统能力通过独立的安装、离线和更新模块适配。桌面保留键盘快捷键和多列排行，移动端采用触控导航、单列内容和可滚动表格。访问者可查看版本并确认更新。浏览器不支持安装入口时，常规网页仍可直接使用。
