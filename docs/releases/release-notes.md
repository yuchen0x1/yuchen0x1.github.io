# 发布历史

## v1.1.1 · 2026-11-27

## 📢 版本概述

本次更新修复页面重绘、代理缓存、发布说明和静态服务器响应头问题，清理未使用依赖及过时开发规划，并补充旧版升级回归验证。现有语言、主题、公开快照缓存和安装方式保持兼容。

## 🔧 改进与优化

- **仓库清理**：移除未使用的 motion、recharts 及其传递依赖，删除两份已过时的一次性开发规划。
- **自动化维护**：同步升级配对的 CodeQL Action 并合并后续升级分组，更新兼容的测试依赖；TypeScript 保持与现有 ESLint 工具链兼容的版本。
- **采集可靠性**：上游请求增加 20 秒超时，失败响应保留真实配额信息，剩余额度为 0 时正确记录。

## 🐛 问题修复

- **静态背景消失**：启用系统“减少动态效果”时，调整窗口大小后重新绘制背景。
- **代理重复请求**：上游返回 304 后刷新缓存有效期，畸形请求 URL 返回 400。
- **更新缓存残留**：新版离线资源安装失败时清理本次不完整缓存，保留旧版可用缓存。
- **发布说明截断**：打包脚本保留更新模板的全部章节，避免遇到二级标题后丢失正文。

## 🔒 安全与兼容性

- **公开代理**：不再读取或转发采集器的 GitHub Token，避免凭据可见的私有仓库内容通过公开代理返回。代理使用匿名公开接口，受 GitHub 匿名 API 速率限制。
- **静态服务器**：修复 Nginx 页面和资源的安全响应头继承，保持版本文件重新验证、带哈希资源长期缓存。
- **采集请求**：禁止自动跟随上游重定向，凭据仅用于固定 GitHub API。

## 🔄 升级与数据迁移

- **兼容性**：支持从 v1.1.0 直接升级，继续使用现有 Service Worker 路径、缓存格式及更新确认流程。
- **配置和数据**：语言、主题及最后可用快照保留，无需迁移。
- **回退方式**：自托管服务器可重新部署上一版完整归档；浏览器在回退构建准备好后仍通过更新确认流程接管。

## 🧪 验证结果

- 13 项前端测试、18 项 Node 测试通过；类型检查、ESLint、生产构建和产物完整性检查通过。
- 全量 npm 依赖审计为 0 漏洞。
- Edge 浏览器完成桌面与 iPhone 14 仿真视口检查；真实 v1.1.0 页面收到更新提示，确认后进入 v1.1.1，旧应用缓存被清理。
- Safari、Firefox 和真实移动设备未在本次独立验证。

## v1.1.0 · 2026-11-18

- 支持通过浏览器安装到桌面或主屏幕，成功缓存后可以离线重新打开页面并查看最后可用的公开快照。
- 新构建准备好后提供更新提醒，用户可以立即刷新或稍后处理，更新下载或完整性检查失败时继续使用旧页面。
- Web 归档提供统一版本、SHA-256、版本元数据和 GitHub 签名来源证明，方便静态服务器、Docker 与 NAS 部署。
- 仓库加入跨系统持续集成、发布校验、依赖更新和定期健康检查。公开数据通过独立分支持续刷新。
- 可选代理减少重复请求，并限制查询范围、请求时间和缓存容量。

## v1.0.1 · 2026-11-18

- 命令面板支持中英文命令搜索、空结果提示和回车执行。终端执行后清空输入，保留结果，并提示未知命令。
- 「Top stars」独立按 Star 数排序，主题筛选显示全部可用主题。首页「Last push」采用所有仓库中最近的推送时间。
- 时间线展示已采集的最新版本发布节点，README 支持表格以及指向原仓库的相对链接。移动端导航可以用同一个按钮打开和关闭。
- 英文模式同步切换个人简介和三个旗舰项目的介绍。
- 历史数据读取失败时仍会显示仓库快照。仓库快照无效时显示缓存数据或可重试的提示。GitHub 未发布正式版本的仓库不会让整份快照显示为采集不完整。
- GitHub Pages 会在快照采集成功后重新部署，页面可以显示新采集的数据。
