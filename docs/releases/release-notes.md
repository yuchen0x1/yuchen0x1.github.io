# 发布历史

## v1.0.1 · 2026-11-18

- 命令面板支持中英文命令搜索、空结果提示和回车执行。终端执行后清空输入，保留结果，并提示未知命令。
- 「Top stars」独立按 Star 数排序，主题筛选显示全部可用主题。首页「Last push」采用所有仓库中最近的推送时间。
- 时间线展示已采集的最新版本发布节点，README 支持表格以及指向原仓库的相对链接。移动端导航可以用同一个按钮打开和关闭。
- 英文模式同步切换个人简介和三个旗舰项目的介绍。
- 历史数据读取失败时仍会显示仓库快照。仓库快照无效时显示缓存数据或可重试的提示。GitHub 未发布正式版本的仓库不会让整份快照显示为采集不完整。
- GitHub Pages 会在快照采集成功后重新部署，页面可以显示新采集的数据。
