# 升级候选与实施决定

以下候选来自当前审计、[研究记录](research/comparison.md) 和 [平台评估](platforms.md)。A 表示核心补齐，B 表示明确的体验或维护收益，C 表示需要进一步证明价值，D 表示当前收益低。难度按当前静态站点规模评估。

| 编号 | 候选与用户价值 | 依据 | 类别 / 优先级 | 难度 | 本轮决定 |
| --- | --- | --- | --- | --- | --- |
| 01 | PR 自动测试，减少页面回归 | GitHub 基础设施审计 | A / 高 | 中 | 实施 CI |
| 02 | Windows、Linux、macOS 构建检查 | 静态项目跨平台开发 | A / 高 | 中 | 实施矩阵 |
| 03 | 正式标签自动生成 Web 归档 | actions/attest | A / 高 | 中 | 实施 |
| 04 | 归档 SHA-256 和版本元数据 | GitHub Release 供应链 | A / 高 | 低 | 实施 |
| 05 | 验证签名工作流来源 | actions/attest | A / 高 | 中 | 实施 |
| 06 | 主分支 PR 和状态检查保护 | 当前无保护 | A / 高 | 中 | 配置并记录实际结果 |
| 07 | 快照独立分支保持自动刷新 | 当前机器人直接写 main | A / 高 | 中 | 实施 |
| 08 | 自动依赖升级 PR | GitHub Dependabot | A / 高 | 低 | 实施 |
| 09 | 定期漏洞检查 | 当前 picomatch 告警 | A / 高 | 低 | 实施，保留失败信号 |
| 10 | 安全报告与私密反馈 | opensource.guide | A / 高 | 低 | 实施 |
| 11 | Issue 和 PR 模板 | opensource.guide | B / 中 | 低 | 实施 |
| 12 | 安装图标和清单 | vite-plugin-pwa、W3C manifest | B / 高 | 中 | 实施 |
| 13 | 离线重新打开作品集 | MDN service-worker、Workbox | B / 高 | 中 | 实施 |
| 14 | 确认刷新后切换版本 | vite-plugin-pwa 生命周期 | B / 高 | 中 | 实施 |
| 15 | 下载损坏时保留旧页面 | Service Worker install 和 integrity | A / 高 | 中 | 实施 |
| 16 | 页面显示网络和当前版本 | PWA 离线体验 | B / 中 | 低 | 实施 |
| 17 | Docker 与 NAS 静态自托管 | AstroPaper、developerFolio 部署示例 | B / 中 | 中 | 实施 |
| 18 | 代理缓存真正命中、限制查询 | 当前代理实现 | A / 高 | 低 | 实施 |
| 19 | 代理超时和缓存容量上限 | 当前代理资源边界 | A / 高 | 低 | 实施 |
| 20 | 真实截图和运行指南 | masterPortfolio、Simplefolio | B / 中 | 低 | 实施 |
| 21 | 生成第三方许可证文本 | 依赖与归档审计 | A / 高 | 中 | 实施 |
| 22 | 记录设备验证范围 | 多平台维护规则 | A / 高 | 低 | 实施 |
| 23 | 每月监测同类项目变化 | 项目长期维护要求 | B / 中 | 低 | 实施只读活动快照 |
| 24 | Release 和线上入口健康检查 | 当前双站点部署 | A / 高 | 低 | 实施 |
| 25 | 全站静态预渲染 | Astro、Hugo、Eleventy | C / 中 | 高 | 延后，需评估 GitHub 数据渲染与 SEO 收益 |
| 26 | 技术博客和内容编辑 | AstroPaper、Chirpy、PaperMod | C / 中 | 高 | 延后，需真实持续内容来源 |
| 27 | 排行可分享 URL 状态 | 搜索和筛选行为 | B / 低 | 中 | 延后，先验证用户需求 |
| 28 | 完整年度贡献图 | github-readme-streak-stats | C / 低 | 高 | 延后，当前事件 API 无年度完整覆盖 |
| 29 | 生成个人 PDF 简历 | masterPortfolio | C / 低 | 中 | 延后，缺少经过作者确认的履历资料 |
| 30 | 主题插件和多用户配置 | metrics 插件体系 | C / 低 | 高 | 延后，当前单作者作品集收益有限 |
| 31 | 仓库徽章和技能图标服务 | skill-icons、github-readme-stats | C / 低 | 中 | 延后，增加外部渲染服务依赖 |
| 32 | 本地原生安装包 | PWABuilder 平台分发 | D / 低 | 高 | 当前浏览业务收益低 |
| 33 | 商店扩展入口 | 浏览器扩展平台评估 | D / 低 | 中 | 当前无跨站操作需求 |
| 34 | 登录、评论和文件上传 | 全栈平台能力清单 | D / 低 | 高 | 与公开只读作品集当前用途缺少关联 |

前 24 项按照实现和实测结果在交付报告记录。后续版本在开发前重新检查受影响的 Web、PWA 和自托管路径。需要新数据源、权限或真实用户资料时，先补齐需求与证据。
